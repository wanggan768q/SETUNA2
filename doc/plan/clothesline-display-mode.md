# 照片晾绳展示模式

## 本次授权范围：仅保存计划文档

本计划保存于当前工程的 `doc/plan/clothesline-display-mode.md`。本次仅保存文档，不修改生产代码、不运行构建或测试、不提交或推送。下面的实施方案仅供审阅，等待用户后续指令后执行。

## Context

截图窗口散落桌面，照片较多时影响操作。新增默认关闭的晾绳模式，将截图集中为挂在绳子上的缩略照片，支持空格临时查看、双击取下操作。关闭功能时保持现有展示行为。

推荐新增独立展示层，保留 `ScrapBase` 作为截图实体：挂起只隐藏原展示窗口，不移动或缩放原图。不采用直接排列原窗口的方案，避免覆盖原位置缓存；不复用现有 50×50 局部裁切的 `CompactScrap` 作为缩略图。不新增依赖或重构无关样式系统。

## 已确认的产品行为

- 设置新增“启用照片晾绳”和“预览位置”，默认关闭；位置三选一：所在显示器居中（默认）、缩略图附近、截图原位置。大小不提供设置：优先原图尺寸，超出目标屏幕工作区时等比缩小。
- 用户从关闭切换到开启时，当前所有存活截图统一上绳；开启期间新增截图、导入、粘贴及回收站恢复的照片自动上绳。
- 全局只有一根可整体拖动、始终置顶的绳子，默认位于当前显示器顶部，使用简单绳线、夹子和照片边框体现晾照片外观。记住拖动后位置；显示器变化时保证可见、可拖回。
- 缩略图完整等比显示，不裁切；单行按创建时间排列，最新在右，超宽通过鼠标滚轮横向浏览；新图加入时滚动到最新。无手动排序、多排绳子或每屏独立绳子。
- 鼠标悬停可见小照片后，无需点击，按空格打开只读、不抢焦点的预览；再按空格关闭。只在命中小照片或预览已打开时消费空格，不影响其他场景的输入；修饰键组合不接管。
- 鼠标离开源小照片和预览区域约 200ms 后自动关闭，允许跨越两者之间的间隙。不会仅因经过另一张照片自动换图。
- 双击小照片将其取下，恢复普通可操作截图窗口；普通截图右键增加“挂回绳子”。关闭模式恢复原展示状态、位置和缩放，不把已有收缩窗口擅自关闭。
- 重启记住开关、绳子位置、预览位置及每张照片挂起/取下状态。重复应用设置不重新挂回取下的照片；明确关闭后再开启才统一收上绳。
- 现有全部隐藏操作同时隐藏晾绳和预览；恢复时不显示挂起原窗口。截图取样前临时隐藏新增展示层，结束后按模式及全部隐藏状态恢复绳子，不恢复旧预览。

## 实施方案

### 1. 最小组件与设置、缓存

新增：
- `SETUNA/Main/Clothesline/ClotheslineController.cs`：挂起集合、生命周期、展示状态、空格钩子与关闭计时；相关小型状态和 P/Invoke 留在同文件。
- `SETUNA/Main/Clothesline/ClotheslineForm.cs`：单根绳子、完整缩略图、整体拖动、横向滚动和命中检测。
- `SETUNA/Main/Clothesline/ClotheslinePreviewForm.cs`：单实例、不激活的只读预览。
- `SETUNATests/ClotheslineTests.cs`：针对状态、序列和布局的集中测试，沿用 MSTest。

修改 `SETUNA/Main/Option/SetunaOption.cs` 与 `OptionForm.cs`、`OptionForm.Designer.cs`：
- 增加默认关闭开关、预览位置枚举、内部绳子位置及位置是否已保存标志；不以 `(0,0)` 代表未设置。
- 沿用现有 XML 序列化与设置窗口手工双向赋值。新增字段采用顶层值类型，并在 `Clone()` 中复制，避免取消设置泄漏；不顺手修复全部旧浅拷贝。
- 拖动结束保存绳子位置，不在每次鼠标移动时写配置。

修改 `SETUNA/Main/Cache/CacheItem.cs`：新增可空 `ClotheslineHanging`，同时加入 `SaveInfo()` 的匿名字段白名单。
- 旧配置缺失字段默认关闭，维持原行为。
- 开启模式启动恢复：`true` 上绳，`false` 保持取下；旧缓存 `null` 视为上绳并保存迁移结果。
- 明确开启时全设为挂起；关闭模式不清零每张缓存状态。启动初始化与运行时开关转换使用不同路径，防止重复 `OptionApply()` 覆盖取下状态。

### 2. 接入统一截图与样式生命周期

复用 `SETUNA/Main/ScrapBook.cs` 的 `AddScrapThenDo()`、`ScrapAdded`、`ScrapRemoved` 与现有缓存绑定，不分别给截图、导入、粘贴实现同套逻辑。
- `AddScrapFromCache()` 在恢复样式之前确定挂起状态；新图在创建样式之前准备展示抑制。仅订阅 `ScrapAdded` 后 Hide 不足以防止异步创建样式重新显示窗口。
- `ScrapBase.cs` 局部增加挂起展示检查，覆盖普通 `Show/Visible` 路径；记录挂起前普通窗与 `StyleForm` 的展示组合，模式关闭时恢复。
- `CCompactStyleItem.cs`、`CompactScrap.cs` 必要时将关联原图和位置初始化从首次 `Load` 拆为可重复安全步骤，允许隐藏状态完成初始化；挂起不调用 `Close()`，避免其关闭事件显示、移动原窗和删除样式。
- 双击取下明确恢复普通窗口；解除既有收缩时复用现有语义，并保护原窗口位置不被收缩窗关闭回调覆盖。
- 图片替换、样式完成（含原地旋转）、移除后更新缩略图和预览；复用现有图片与样式事件，不只依赖图片属性变化。
- 所有绳子拖动、缩略布局、预览定位都不写原图 `Location/Scale/TargetLocation`，避免触发 `CacheManager` 的位置回写。
- 复用现有关闭/回收站流程移除截图，不另建图片存储。删除当前预览源时立即关闭，并取消排队的预览请求。

### 3. 展示、预览和按键

- 用 WinForms 原生绘制/控件实现，无新 UI 框架。缩略图使用等比完整显示；不要为每张照片长期复制整张大图。明确图片所有权，替换和删除时避免绘制已释放图片；预览所需副本及时释放。
- 用目标显示器 `WorkingArea` 限制预览尺寸和坐标，支持负坐标、横竖图和极长图。原位置模式只读取原截图位置。启动恢复后统一完成排序，不按缓存的 Z-order 排列照片。
- 预览使用 `ShowWithoutActivation`、`WS_EX_NOACTIVATE` 及必要的鼠标激活处理，不转发编辑、拖动或截图样式快捷键。
- 使用一个 `WH_KEYBOARD_LL` 钩子，不全局注册裸 Space。回调只处理轻量命中与按键状态，图像、UI 和缓存工作投递到 UI 线程。
- 跟踪物理按下与本轮是否消费：首个 keydown 切换一次，重复 keydown 不重复切换；keyup 按首个 down 的决定消费。首次 down 已透传时，按住后移入不能中途接管；移出、自动关闭、关闭模式不能漏放被消费按键的后半段。
- `nCode < 0` 直接透传；正确处理 x64 签名、委托存活与初始化时已按住空格。钩子注册失败明确提示并保持原截图可访问，不静默启用不完整模式。
- 约 200ms 关闭计时检查源缩略图和预览两个实际矩形，而不是其外包矩形；滚动移出视口、隐藏、删除也使预览失效。关闭模式后排队的 Show 不得重新打开预览。

### 4. 主窗体、层级、隐藏与清理

修改 `SETUNA/Mainform.cs`：
- 在层级管理初始化后、缓存恢复前创建 Controller；设置应用先配置，再按启动/显式开关语义更新模型。
- `ScrapMenuOpening()` 动态提供“挂回绳子”，仅模式开启且目标适用时显示，不累积菜单项；截图列表激活挂起项时定位其缩略图，不隐式 Show 原图。
- `StartCapture()` 在 `ShowCapture()` 之前暂停新增展示层：后者在线程取样后才显示捕获窗，不能等其 `VisibleChanged`。`EndCapture()` 的 `finally` 清除捕获暂停；成功、取消、异常统一覆盖，捕获中新图加入不得提前显示绳子。
- `CommandCutRect()` 的直接 `CopyFromScreen` 路径同样以 `try/finally` 暂停/恢复新增展示层。不在公共抓屏方法里触碰 UI，不改变普通截图现有的被捕获行为。
- `SetAllScrapsActive()` 与 `ScrapBook.ShowAllScrap()/HideAllScrap()` 两套入口都接入。全部隐藏和捕获暂停分别记录；隐藏期间新增/取下/切换模式不留下失效恢复列表，恢复前过滤已释放窗口。模式关闭保留旧展示路径。
- 应用退出停 Timer、解绑事件、释放图片与窗体、确定性卸钩；不调用 `CloseAllScrap()` 清理展示层，以免进入用户删除/回收站路径。关闭模式时若仍在消费一轮空格，配对 keyup 后卸钩；进程退出直接清理。

修改 `SETUNA/Main/Layer/LayerManager.cs`：新窗沿用 `BaseForm` 注册方式；刷新末尾对可见的绳子和预览按此顺序置顶，保证预览高于绳子，不参与截图缓存的排序写回。绳子始终置顶，不受原普通截图置顶开关影响。

## 验证

执行阶段运行（本次规划不运行构建或测试）：

```powershell
dotnet build SETUNA/SETUNA.csproj
dotnet test SETUNATests/SETUNATests.csproj
```

自动化测试集中覆盖：
1. 旧 XML/JSON 默认值、新缓存字段往返、新选项 Clone 隔离。
2. 显式开启全部挂起与启动保留取下状态的区别，重复应用设置不重置；全隐藏与捕获暂停互不清除。
3. 空格 down/repeat/up、移出后 up、关闭模式后 up、按住再移入、非命中/修饰键透传。
4. 横竖/极长图等比适配、负坐标工作区、三种位置夹紧。
5. 可行的 STA 生命周期检查：挂起与恢复不改原位置/Scale；收缩样式不泄漏可见窗口；删除后排队预览不会复活。测试使用临时缓存，不触碰真实用户截图。

人工验收：
- 默认关闭：截图、收缩、导入、粘贴、列表激活及原快捷键保持原样。
- 开启已有照片全上绳；绳线/夹子可辨识；整体拖动、记住位置、滚轮无需点击、最新照片在右。
- 记事本保持前台：命中时空格不漏字、不抢焦点，非命中正常输入；长按只切一次；鼠标跨间隙进入预览不闪退，移开后关闭。
- 双击取下可正常操作，右键挂回；关闭恢复，重启保留每张状态；包含创建样式为收缩、旋转、回收站恢复。
- 两种全部隐藏入口、隐藏期间新增/切换模式，以及普通截图和矩形抓屏成功/取消/异常路径；捕获结果不包含新增展示层。
- 多屏负坐标、显示器拔插、100%/150%/200% 缩放及跨屏拖动。先核实当前 DPI 上下文，不为本功能顺手更改整个进程 DPI 模式。
